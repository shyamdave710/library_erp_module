Security & Privacy

Enterprise-Grade Security. Zero External Dependency.

Your business data stays on your infrastructure. Every access is validated, logged, and revocable.

🔑

Personal Token Access

Each employee receives a unique 43-character cryptographically secure token. No shared passwords. Revoke any user in one click.

🛡️

Permission-Controlled

Admins choose exactly which departments each employee can access. Enforced at the server level on every single request.

📋

Full Audit Trail

Every question is logged in Odoo — who asked, which tool, when, and the result. Nothing is hidden from administrators.

🏠

Data Never Leaves

All data fetching happens within your own infrastructure. No Odoo data is sent to any external AI service or third-party cloud.

🔒

Read-Only by Default

Amogh AI is a read-only intelligence layer. Nothing in Odoo can be modified through AI queries — safe for all employee levels.

⏱️

5-Min Revocation Cache

Token validation is cached for performance. Deactivate a user with one click — access fully revoked within 5 minutes maximum.
